# HuangFlow 流量監測

[下載最新 Android APK](https://github.com/ziyuanh100/huang/raw/refs/heads/huangflow-downloads/HuangFlow.apk)

適用於 Android 8.0 以上。已安裝 0.1.0 的使用者可直接覆蓋安裝，沿用原本的流量紀錄。

## 0.2.0 更新內容

- 開啟 App 時檢查新版，Android 也會在背景排程檢查。
- 預設可透過 Wi-Fi 或行動網路自動下載新版 APK，完成後通知使用者確認安裝。
- 「設定 → App 更新」可關閉自動下載、手動檢查或安裝已下載的版本。
- 安裝前檢查 APK 大小、SHA-256、套件名稱、版本及開發者簽章。

系統通知須取得通知權限。安裝更新時，Android 可能要求允許 HuangFlow 安裝應用程式。用量歷史仍保存於本機。
