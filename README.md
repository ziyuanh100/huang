## 0.5.0 首頁、每日摘要與 App 提醒

- 首頁將行動網路本期用量與額度合併。切換日期或 Wi-Fi 時顯示該條件的用量，紀錄不足時標示涵蓋天數。方案支援選擇吃到飽。
- 每日趨勢與主要 App 移到首頁前段，即時速度與未啟動的計時器縮小顯示。
- 點選每日長條圖，可在原頁查看當天用量與最高用量 App，切換前後一天，再決定是否進入排行。
- 設定內的提醒清單隨時可新增提醒。支援以名稱或套件搜尋 App，既有提醒可從編輯頁直接關閉。
- 升級時保留本機紀錄。舊版已修改過設定且額度為零時，因舊格式無法區分當初的選擇，會顯示「未設流量上限」；可在設定明確選擇吃到飽。

## 0.4.0 操作更新

- 期間面板可切換常用期間、單日與整月。翻月或選日期後，按「查看」才會套用，取消會保留原查詢。
- 在 App 排行點選排序依據即可重排，搜尋條件會保留。
- 從 App 明細或設定清單編輯提醒，儲存與返回都會回到原來的位置。儲存失敗時可直接修改重試。
- 速度單位、自動下載開關、更新提示與備份還原確認採用一致的深淺色介面。

## 0.3.0 更新內容

- 點進單日用量排行後，可返回原本的期間、網路類型及捲動位置。
- 排行可搜尋名稱或套件，支援按總流量、下載、上傳及背景用量排序。
- 歷史紀錄新增年度用量，可從年度逐月往下查到每日與各 App 明細。
- 設定集中管理方案與個別 App 提醒，編輯中的方案草稿可在當次使用中繼續修改。
- 部分歷史時段及缺少紀錄的日期清楚標示。資料不足時，剩餘額度與預估暫緩顯示。
- 計時中可查看已用流量，連續點按會忽略重複的開啟或結束操作。
- 手機介面支援系統深淺色，修正從安裝來源權限設定返回時的更新流程。
