## 0.3.0 更新內容

- 點進單日用量排行後，可返回原本的期間、網路類型及捲動位置。
- 排行可搜尋名稱或套件，支援按總流量、下載、上傳及背景用量排序。
- 歷史紀錄新增年度用量，可從年度逐月往下查到每日與各 App 明細。
- 設定集中管理方案與個別 App 提醒，編輯中的方案草稿可在當次使用中繼續修改。
- 部分歷史時段及缺少紀錄的日期清楚標示。資料不足時，剩餘額度與預估暫緩顯示。
- 計時中可查看已用流量，連續點按會忽略重複的開啟或結束操作。
- 手機介面支援系統深淺色，修正從安裝來源權限設定返回時的更新流程。
